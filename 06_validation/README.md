# Validation

Mỗi file `VAL-<insight_id>.md`: insight cần kiểm chứng, query/nguồn nội bộ dùng, kết quả, kết luận (giữ / nâng / bác bỏ).

Nguồn nội bộ: Metabase (booking, payment fail), GA4 (funnel), Clarity (field abandonment), CS/bot chat, search log (BI-2775).

**Không commit raw data nội bộ hay PII lên repo**, chỉ commit số tổng hợp.
